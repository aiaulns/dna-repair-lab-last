DNA REPAIR LAB v3.0 — ВИРТУАЛЬНАЯ ЛАБОРАТОРИЯ ПО РЕПАРАЦИИ ДНК
================================================================

ЗАПУСК
1. Распакуйте архив.
2. Откройте index.html в Chrome / Edge / Firefox.
3. Перейдите к «3D-молекулы» — для отображения экспериментальных структур потребуется подключение к интернету.
4. Разделы «Анимация BER», «Практикум», «Теория», «Тест» работают без подключения к интернету.

ФАЙЛЫ
index.html             — страницы лаборатории
assets/style.css       — дизайн и адаптивная верстка
assets/app.js          — логика, анимации и интерактивные задания

ЧТО РЕАЛЬНОЕ, А ЧТО СХЕМАТИЧЕСКОЕ
- 3D-модуль загружает реальные экспериментально определённые атомные структуры PDB.
- Для загрузки используется 3Dmol.js и сайт files.rcsb.org. Без интернета реальный 3D-модуль недоступен.
- Если 3D-модуль не загрузился, отображается анимированная учебная спираль, явно обозначенная как запасная схема.
- Анимация BER — понятная учебная схема 6 этапов; не является физическим моделированием траекторий молекул.
- При переключении ферментов отображаются РАЗНЫЕ экспериментальные комплексы, не выровненные в одном пространстве и не представляющие одну непрерывную реакцию.
- Практикум показывает один вариант короткозаплаточного BER человека; другие варианты репарации могут отличаться.

СТРУКТУРЫ PDB (ПРОВЕРЕННЫЕ ИДЕНТИФИКАТОРЫ)
1SSP — Homo sapiens uracil-DNA glycosylase / DNA: https://www.rcsb.org/structure/1SSP
5DFI — Human APE1 phosphorothioate substrate complex: https://www.rcsb.org/structure/5DFI
2FMS — DNA polymerase beta / gapped DNA substrate: https://www.rcsb.org/structure/2FMS
3L2P — Human DNA ligase III / DNA: https://www.rcsb.org/structure/3L2P

ПРОСМОТРЩИК

3Dmol.js citation: Rego N, Koes D. 3Dmol.js: molecular visualization with WebGL. Bioinformatics. 2015;31(8):1322-1324.

ЕСЛИ 3D НЕ РАБОТАЕТ
- Проверьте подключение к интернету и возможность открытия сайтов 3Dmol.org и files.rcsb.org.
- Нажмите «Повторить загрузку».
- Можно скачать PDB-файл с RCSB вручную и открыть его через кнопку «Выбрать PDB». Но сама библиотека 3Dmol.js при первом запуске всё равно должна загрузиться из интернета.
- Попробуйте Chrome или Edge с поддержкой WebGL. При этом весь остальной сайт продолжит работать.
